# MundyMech

See the {ref}`MundyMech API directory <dir_mundy_core_mech>`.

MundyMech is under construction. It contains mechanical elements and force laws for building multibody models.

The current public primitives include:

- {ref}`mundy::mech::BallJoint <exhale_class_classmundy_1_1BallJoint>`
- {ref}`mundy::mech::HookeanSpring <exhale_class_classmundy_1_1HookeanSpring>`
- {ref}`mundy::mech::FeneSpring <exhale_class_classmundy_1_1FeneSpring>`
- {ref}`mundy::mech::TorsionalSpring <exhale_class_classmundy_1_1TorsionalSpring>`

Further mechanical models and integration hooks will be added as the library matures.
