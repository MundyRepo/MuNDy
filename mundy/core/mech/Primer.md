# MundyMech {#MundyMech}

\brief Mechanical primitives and utilities (under construction).

See the \ref mundy/core/mech "MundyMech directory reference".

MundyMech is under construction. It contains mechanical elements and force laws for building multibody models.

The current public primitives include:

- `mundy::mech::BallJoint`
- `mundy::mech::HookeanSpring`
- `mundy::mech::FeneSpring`
- `mundy::mech::TorsionalSpring`

Further mechanical models and integration hooks will be added as the library matures.
